# План реализации: Plugin Tags

## Обзор

Поэтапное добавление поддержки тегов (`tags text[]`) для плагинов. Изменения проходят снизу вверх: миграция БД → proto → домен → registry → API → SDK. Каждый шаг строится на предыдущем, код интегрируется инкрементально.

## Примечания

- Задачи, отмеченные `*`, являются опциональными и могут быть пропущены

- Для property-тестов используется `testing/quick` из стандартной библиотеки Go
- Каждая задача ссылается на конкретные требования для трассируемости
