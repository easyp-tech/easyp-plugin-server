# Отчет о реализации: plugin-migration-cli

## Обзор
В данном отчете документируется процесс реализации команды миграции плагинов `easyp-svc plugins migrate`.

## Использованные команды
- **Test:** `go test ./...`
- **Build:** `go build -o easyp-svc ./cmd/easyp-svc/`
- **Lint:** `golangci-lint run ./...`

## Измененные файлы
- `cmd/easyp-svc/main.go` — Добавление подкоманды `plugins migrate` и соответствующих флагов.
- `cmd/easyp-svc/migrate.go` — Реализация логики обхода папок, gRPC вызовов и Mini-TUI.
- `internal/serve/http.go` — Исправление вызова `errors.Is` для `http.ErrServerClosed`.
- `cmd/easyp-svc/start.go` — Автоматический фикс форматирования lll/godot.
- `internal/database/goosemigrate/goosemigrate.go` — Автоматический фикс импортов (gci).
- `sdk/config.go` — Автоматический фикс форматирования полей.
