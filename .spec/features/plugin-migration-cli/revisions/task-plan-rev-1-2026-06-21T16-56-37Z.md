**GOAL:** Подключить отправку запросов на сервер через gRPC SDK.

1. **[MODIFY] [migrate.go](file:///Users/zergslaw/Documents/Projects/easyp-tech/service/cmd/easyp-svc/migrate.go):**
   - Инициализировать gRPC клиент EasyP через `sdk.NewClient(addr, sdk.WithInsecure())`. Обеспечить корректное закрытие соединения через `defer`.
   - Для каждого плагина из списка сканирования формировать конфигурационный объект:
     `config = map[string]any{"command": []any{pluginsPrefix + "/" + group + "/" + name + "/" + version + "/plugin"}}`

## T-5: Интеграционное тестирование с `test_registry` (Вместо юнит-тестов)

*_Requirements: REQ-1.2, REQ-3.2, REQ-4.1, REQ-5.1, REQ-5.2, REQ-5.3_*
*_Complexity: standard_*

**GOAL:** Проверить работоспособность мигратора на тестовом наборе плагинов.

### Подзадачи:
1. **Интеграционная верификация**:
   - Шаг 1: Собрать плагины из директории `test_registry/` во временную папку `.tmp/plugins/`.
   - Шаг 2: Убедиться, что сервер EasyP запущен локально (на порту 8080).
   - Шаг 3: Выполнить команду миграции:
     `./easyp-svc plugins migrate .tmp/plugins/`
     *Ожидается:* счетчик зарегистрированных плагинов = 3. Успешный вывод интерактивного интерфейса.
   - Шаг 4: Выполнить команду миграции повторно:
     `./easyp-svc plugins migrate .tmp/plugins/`
     *Ожидается:* все 3 плагина пропускаются со статусом `AlreadyExists` (зарегистрировано = 0, пропущено = 3).
   - Шаг 5: Проверить работу фильтра:
     `./easyp-svc plugins migrate .tmp/plugins/ --filter "grpc/*"`
     *Ожидается:* обработан только плагин `grpc/go:v1.5.1`.
   - Шаг 6: Проверить неинтерактивный режим:
     `./easyp-svc plugins migrate .tmp/plugins/ --non-interactive`
     *Ожидается:* вывод чистых логов в stdout без спиннеров и возвратов каретки.
